## Before a research claim

1. Acquire permitted material and inspect its provenance and licensing.
2. Group parent journeys and all derived paraphrases, screenshots and prefixes before splitting.
3. Have independent reviewers annotate observable concerns and legitimate lookalikes, including disagreements.
4. Freeze thresholds and comparison protocol on development/validation material.
5. Compare latest-message model, available-conversation model and structured case processing on identical available evidence.
6. Report unavailable cases, false warnings, warning timing, repetition and latency alongside detection coverage.
7. Retire any test set that influences a design correction into the regression collection.

The existing engineering collection satisfies none of the independence or representativeness requirements for a deployment accuracy claim.
